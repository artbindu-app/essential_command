## MongoDB Learning

### Installation Steps (Mac)

brew update: `brew update`

Register official MongoDB Homebrew Tap: `brew tap mongodb/brew`

Install MongoDB: `brew install mongodb-community`

Enable MongoDB background service: `brew services start mongodb-community`

Check MongoDB: `mongosh`

Disabled MongoDB background service: `brew services stop mongodb-community`

Check brew ServiceList: `brew services list`
